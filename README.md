# 🎙️ LifeOS AI — Autonomous Voice-First Personal Super Assistant

> **LifeOS AI** is an autonomous, voice-first personal assistant designed to continuously monitor authorized sources (Gmail, Google Classroom, Google Calendar, and local files), detect schedule and assignment changes, compute deterministic priority rankings, execute permitted actions, and deliver proactive spoken briefings without requiring manual prompts.

### 🌟 Key Highlights
- **Voice-First & Proactive**: Conversational voice interface with text-to-speech proactive alerts when urgent coursework or schedule shifts occur.
- **Google Workspace Integration**: Direct OAuth synchronization with Gmail, Google Classroom, and Google Calendar.
- **Autonomous Intelligence Loop**: 10-step continuous cycle (Detect → Contextualize → Prioritize → Decide → Act → Verify → Speak).
- **Automated Academic Problem Solver**: Extracts coursework requirements from incoming emails and generates structured derivations, code, and submission drafts.
- **Deterministic Prioritization**: Weighted scoring based on urgency, importance, consequence, and goal relevance.
